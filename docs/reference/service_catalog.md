# Service Catalog Reference

This document outlines the core consulting offerings, categorizations, and minimum pricing structures based on proven capabilities.

## 1. Backend Architecture & Data Engineering
**Target:** Marketing agencies, e-commerce, logistics.
*   **Service: Automated Data Integration / ETL Pipelines**
    *   *Description:* Connecting disparate APIs (e.g., Facebook Ads to Google Data Studio) to eliminate manual reporting.
    *   *Minimum Pricing:* $1,500 flat fee per pipeline.
*   **Service: Legacy System Integration**
    *   *Description:* Building custom middleware to sync legacy CRMs with modern web portals.
    *   *Minimum Pricing:* $2,000 flat fee.

## 2. DevOps & Infrastructure Automation
**Target:** Post-Seed SaaS startups, non-tech traditional businesses, local MSPs.
*   **Service: CI/CD Pipeline Construction**
    *   *Description:* Automating test and deployment pipelines via GitHub Actions and Docker.
    *   *Minimum Pricing:* $1,000 flat fee.
*   **Service: Infrastructure as Code (IaC) Migration**
    *   *Description:* Moving manual server configurations to Ansible/Terraform for reproducible infrastructure.
    *   *Minimum Pricing:* $1,500 flat fee.
*   **Service: Monthly Infrastructure Maintenance (Retainer)**
    *   *Description:* Ongoing monitoring, security patching, and server uptime management.
    *   *Minimum Pricing:* $500 - $1,000 / month.

## 3. Advanced Automation & AI Integration
**Target:** Law firms, BPOs, data-heavy enterprises.
*   **Service: Semantic Parsing Pipelines**
    *   *Description:* Automating discovery and contract analysis for unstructured documents.
    *   *Minimum Pricing:* $2,000 flat fee.
*   **Service: Internal LLM Workflows**
    *   *Description:* Implementing private, agentic workflows for internal data triage.
    *   *Minimum Pricing:* $2,500 flat fee.
